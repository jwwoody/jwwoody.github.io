# jwwoody.github.io

Personal site for Jeffrey Woodbury, served by GitHub Pages at https://jwwoody.github.io.

Plain HTML and CSS, plus one small script for the optional baseball game. No build step, no
cookies, no analytics, no third-party scripts or fonts.

- `index.html` is the home page
- `game.js` is the baseball game on the field; the page works fully without it
- `policies.html` covers privacy, cookies, terms and accessibility

When `style.css` or `game.js` changes, bump the `?v=` number where the pages link them so
browsers skip their cached copy.
