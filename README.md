# jwwoody.github.io

Personal site for Jeffrey Woodbury, served by GitHub Pages at https://jwwoody.github.io.

Plain HTML and CSS. No build step, no JavaScript, no cookies, no analytics, no third-party
scripts or fonts.

- `index.html` is the home page
- `policies.html` covers privacy, cookies, terms and accessibility
